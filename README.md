# GateSmart-Smart-Gate-Visitors-Management-
Web app GateSmart (Smart Visitor Management System)
<img width="3758" height="1625" alt="dashboard" src="https://github.com/user-attachments/assets/5f6e3c36-1541-4035-817f-34f8bbc4fff1" />
made in Visual studio, ASP. NET MVC
type: web application
Database: SSMS 
Basic Features: 
1. Manage Users (admin/guard etc)
2. Manage Residents
3. Manage Societies
4. Manage Visitors
5. Manage/Add Visits (Vistior pass with deatails and QR code, download pass, checkout/scan QR code)
6. Authentication (Login/Registeration)
Advance Features:
1. Visitors Analytics View (bar chart, monthly visists summary)
2. Visits Report (downloadable pdf report with data and chart)
